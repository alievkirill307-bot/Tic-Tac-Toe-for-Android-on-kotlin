Простая и легендарная игра **«Крестики-нолики»** для Android.  
Сразитесь с другом на одном устройстве — классика в минималистичном исполнении.

## 📱 О проекте

Это приложение реализует игру для двух игроков на одном телефоне (pass-and-play).  
Интерфейс максимально прост: поле 3×3, отображение текущего игрока, подсчёт побед и возможность начать новую партию.

Проект написан на **Kotlin** с использованием стандартных компонентов Android и может служить отличным примером для изучения основ разработки мобильных игр.

## ✨ Возможности

- Игра для двух игроков на одном устройстве.
- Отображение текущего хода (X или O).
- Автоматическое определение победителя или ничьей.
- Счётчик побед для каждого игрока.
- Кнопка сброса счёта и поля для новой игры.
- Готовый к установке APK-файл в корне репозитория.

## 🛠 Технологии и инструменты

- **Язык:** Kotlin
- **Минимальная версия Android:** API 24 (Android 7.0 Nougat)
- **Система сборки:** Gradle Kotlin DSL (`build.gradle.kts`)
- **Среда разработки:** Android Studio (рекомендуемая)

## 🚀 Как запустить проект

### Предварительные требования

- Установленная [Android Studio](https://developer.android.com/studio) (последняя стабильная версия).
- Устройство или эмулятор с Android 7.0 (API 24) или выше.

### Установка и запуск из исходников

   git clone https://github.com/alievkirill307-bot/Tic-Tac-Toe-for-Android-on-kotlin.git

 
   Запустите Android Studio, выберите «Open an existing project» и укажите путь к скачанной папке.

3. **Запустите приложение:**  
   Подключите Android-устройство или запустите эмулятор, затем нажмите кнопку `Run` (зелёный треугольник) в панели инструментов.

### Установка готового APK

Если вы не хотите собирать проект самостоятельно:

1. Скачайте файл [`Results.apk`](Results.apk) из корня репозитория на своё Android-устройство.
2. Откройте скачанный файл и разрешите установку из неизвестных источников (если потребуется).
3. Запустите игру!
